# 🚀 Projets et Exercices - PHP

Ce repository est une collection d'exercices et de mini-projets en PHP, conçus pour explorer les fondamentaux du langage, de la gestion de formulaires à l'interaction avec des bases de données MySQL.

## ✨ Objectifs Pédagogiques

- **Maîtriser les bases de PHP** : variables, conditions, boucles, fonctions.
- **Gérer les formulaires** : traitement des données `GET` et `POST`.
- **Interagir avec le client** : gestion des sessions et des cookies.
- **Manipuler les structures de données** : tableaux simples et associatifs.
- **Se connecter à une base de données** : exécution de requêtes SQL (CRUD) avec PHP.

## 📂 Contenu du Repository

Ce repository est organisé en plusieurs scripts PHP, chacun se concentrant sur un aspect spécifique du développement web.

### 1. Gestion de Formulaires & Données Utilisateur

Ces scripts montrent comment récupérer et traiter les données envoyées par l'utilisateur.

| Fichier                  | Description                                                                 |
| ------------------------ | --------------------------------------------------------------------------- |
| `formulaireget.html`     | Formulaire utilisant la méthode `GET`.                                      |
| `recup_get.php`          | Script de réception et d'affichage des données `GET`.                       |
| `formulairepost.html`    | Formulaire utilisant la méthode `POST`.                                     |
| `recup_post.php`         | Script de traitement des données `POST`.                                    |
| `recup_hidden.php`       | Utilisation des champs de formulaire cachés (`hidden`).                     |
| `calculsSession.php`     | Exemple de calculs dont les résultats sont stockés en session.              |
| `recup_session.php`      | Récupération et affichage des données de session.                           |

### 2. Algorithmes & Jeux

Une série de scripts ludiques pour s'exercer à la logique de programmation.

| Fichier             | Description                                                              |
| ------------------- | ------------------------------------------------------------------------ |
| `loto.php`          | Simulation d'un tirage de loto.                                          |
| `casino.php`        | Un mini-jeu de casino.                                                   |
| `trouvernb.php`     | Jeu "trouver le nombre" où l'ordinateur doit deviner un chiffre.         |
| `matrice.php`       | Manipulation et affichage de tableaux à deux dimensions (matrices).      |
| `compteurclic.php`  | Un compteur de clics simple utilisant les sessions.                      |

### 3. Interaction avec Base de Données (PHP & MySQL)

Ces scripts démontrent la connexion entre PHP et une base de données MySQL pour créer des applications dynamiques.

| Fichier                       | Description                                                              |
| ----------------------------- | ------------------------------------------------------------------------ |
| `dbfonctions.php`             | Fonctions réutilisables pour la connexion et les requêtes à la BDD.      |
| `masociete.php`               | Application de gestion des employés d'une société (CRUD).                |
| `zooproforma.php`             | Interface de gestion pour la base de données du zoo.                     |
| `dauphins.php`                | Application en lien avec la base de données sur les dauphins.            |

## 🚀 Comment Utiliser

Pour exécuter ces projets, vous aurez besoin d'un environnement de développement web local comme WAMP, XAMPP ou MAMP.

1.  **Clonez ce repository** dans le dossier `www` ou `htdocs` de votre serveur local.
2.  **Assurez-vous** que les services Apache et MySQL sont démarrés.
3.  **Importez les bases de données** correspondantes depuis le repository `Projets-MySQL` via phpMyAdmin.
4.  **Accédez aux fichiers** via votre navigateur (ex: `http://localhost/Projets-PHP/formulaireget.html`).
