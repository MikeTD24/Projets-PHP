_# 🚀 Projets et Exercices - PHP_

_Ce repository est une collection d'exercices et de mini-projets en PHP, conçus pour explorer les fondamentaux du langage, de la gestion de formulaires à l'interaction avec des bases de données MySQL._

_## ✨ Objectifs Pédagogiques_

_- **Maîtriser les bases de PHP** : variables, conditions, boucles, fonctions._
_- **Gérer les formulaires** : traitement des données `GET` et `POST`._
_- **Interagir avec le client** : gestion des sessions et des cookies._
_- **Manipuler les structures de données** : tableaux simples et associatifs._
_- **Se connecter à une base de données** : exécution de requêtes SQL (CRUD) avec PHP._

_## 📂 Contenu du Repository_

_Ce repository est organisé en plusieurs scripts PHP, chacun se concentrant sur un aspect spécifique du développement web._

_### 1. Gestion de Formulaires & Données Utilisateur_

_Ces scripts montrent comment récupérer et traiter les données envoyées par l'utilisateur._

_| Fichier                  | Description                                                                 |_
_| ------------------------ | --------------------------------------------------------------------------- |_
_| `formulaireget.html`     | Formulaire utilisant la méthode `GET`.                                      |_
_| `recup_get.php`          | Script de réception et d'affichage des données `GET`.                       |_
_| `formulairepost.html`    | Formulaire utilisant la méthode `POST`.                                     |_
_| `recup_post.php`         | Script de traitement des données `POST`.                                    |_
_| `recup_hidden.php`       | Utilisation des champs de formulaire cachés (`hidden`).                     |_
_| `calculsSession.php`     | Exemple de calculs dont les résultats sont stockés en session.              |_
_| `recup_session.php`      | Récupération et affichage des données de session.                           |_

_### 2. Algorithmes & Jeux_

_Une série de scripts ludiques pour s'exercer à la logique de programmation._

_| Fichier             | Description                                                              |
_| ------------------- | ------------------------------------------------------------------------ |_
_| `loto.php`          | Simulation d'un tirage de loto.                                          |_
_| `casino.php`        | Un mini-jeu de casino.                                                   |_
_| `trouvernb.php`     | Jeu "trouver le nombre" où l'ordinateur doit deviner un chiffre.         |_
_| `matrice.php`       | Manipulation et affichage de tableaux à deux dimensions (matrices).      |_
_| `compteurclic.php`  | Un compteur de clics simple utilisant les sessions.                      |_

_### 3. Interaction avec Base de Données (PHP & MySQL)_

_Ces scripts démontrent la connexion entre PHP et une base de données MySQL pour créer des applications dynamiques._

_| Fichier                       | Description                                                              |
_| ----------------------------- | ------------------------------------------------------------------------ |_
_| `dbfonctions.php`             | Fonctions réutilisables pour la connexion et les requêtes à la BDD.      |_
_| `masociete.php`               | Application de gestion des employés d'une société (CRUD).                |_
_| `zooproforma.php`             | Interface de gestion pour la base de données du zoo.                     |_
_| `dauphins.php`                | Application en lien avec la base de données sur les dauphins.            |_

_## 🚀 Comment Utiliser_

_Pour exécuter ces projets, vous aurez besoin d'un environnement de développement web local comme WAMP, XAMPP ou MAMP._

_1.  **Clonez ce repository** dans le dossier `www` ou `htdocs` de votre serveur local._
_2.  **Assurez-vous** que les services Apache et MySQL sont démarrés._
_3.  **Importez les bases de données** correspondantes depuis le repository `Projets-MySQL` via phpMyAdmin._
_4.  **Accédez aux fichiers** via votre navigateur (ex: `http://localhost/Projets-PHP/formulaireget.html`)._
